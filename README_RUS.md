# Code Typer

Оффлайн десктопный тренажёр слепой печати для программистов на Go, Wails и vanilla JavaScript.

Идея не в том, чтобы учить алгоритмы. Идея в том, чтобы синтаксис кода стал мышечной памятью: скобки, табы, переносы строк, обращения к map, каналы, циклы, сигнатуры функций и частые конструкции должны печататься автоматически.

## Что уже есть

- Десктопное приложение на Wails.
- Оффлайн-набор упражнений со сниппетами Go, JavaScript и Python.
- Обработка физических QWERTY-клавиш, поэтому можно печатать даже при включённой русской раскладке ОС.
- Поле ввода в стиле редактора кода с номерами строк.
- Текущая скорость, точность, количество опечаток и progress bar.
- Подсказки на клавиатуре для ожидаемых клавиш, нажатых клавиш, сервисных клавиш и ошибок.
- Heatmap после завершения упражнения по всем ошибкам, включая исправленные через Backspace.
- Настройки единиц скорости, ширины таба, режима ввода, подсказок клавиатуры, сгенерированных звуков, прозрачности фона и акцентного цвета.

## Куда идём

Code Typer должен оставаться минималистичным и offline-first.

План лежит в:

- `ROADMAP.md`
- `ROADMAP_RUS.md`

Ближайшие направления:

- Постоянная статистика и графики прогресса.
- Пулы упражнений и тематические наборы сниппетов.
- Гибкий ввод табуляции: принимать реальный Tab или настроенное количество пробелов там, где это уместно.
- Typed-buffer модель для более IDE-похожего поведения при ошибках перед переносом строки.
- Кастомные звуки, пресеты тем, подсветка синтаксиса и импорт пользовательских сниппетов.

## Разработка

Нужно:

- Go
- Node.js и npm
- Wails v2 CLI

Установить зависимости фронтенда:

```sh
cd frontend
npm install
```

Запустить приложение в dev-режиме:

```sh
wails dev
```

Wails также поднимает browser target, обычно:

```txt
http://localhost:34115
```

Открывай этот URL, если нужны devtools в браузере и при этом доступ к Go-методам, проброшенным через Wails.

## Сборка

Собрать десктопное приложение:

```sh
wails build
```

На macOS приложение появится здесь:

```txt
build/bin/code-typer.app
```

## Проверка

Полезные команды перед коммитом:

```sh
cd frontend
npm run build
```

```sh
go test ./...
```

```sh
wails build
```

Если Go embed cache ругается на старый Vite asset hash после сборки фронтенда, перезапусти `go test` со свежим `GOCACHE` или запускай тесты только после полного завершения frontend build.
