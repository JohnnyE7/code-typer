# Code Typer Roadmap

## Ближайшие задачи

- Экран завершения упражнения: heatmap клавиатуры, мигающий Enter на клавиатуре, текущая статистика и изменения относительно прошлого упражнения.
- Почистить completion UX: не дублировать верхнюю статистику под редактором и не рисовать второй отдельный Enter под полем ввода.
- Постоянная статистика: график последних упражнений, где скорость растёт вверх, а ошибки уходят вниз.
- Разобраться с редким ранним рестартом или переключением упражнения после запуска приложения.
- Гибкий ввод табуляции: если в сниппете ожидается `Tab`, принимать либо реальную табуляцию, либо ровно настроенное количество пробелов. В подсказках попеременно мигать Tab и Space.
- Пулы упражнений: после завершения рандомно подкидывать следующую задачу из активного пула. Позже сделать тематические пулы, например Go channels, goroutines, maps, slices, syntax drills.
- Модель typed buffer: если вместо Enter в конце строки нажали неправильный символ, он должен появиться на текущей строке и не должен перебрасывать пользователя на следующую строку до реального Enter.
- Историческая heatmap: считать все ошибки, включая те, которые потом были исправлены через Backspace.
- Подсветка сервисных клавиш: показывать зажатые Shift, Control, Option, Command и похожие клавиши.
- Кастомные звуки: выбор своего файла для звука ошибки, при этом оставить текущий сгенерированный fallback.
- Настройки темы: прозрачность фона, акцентный цвет, сохранённые пресеты.
- Переключатель подсветки синтаксиса: режим блокнота без подсветки и IDE-режим с подсветкой.
- Написать нормальный README: идея продукта, локальная разработка, Wails build, список текущих фич и ограничений.
