# Code Typer Roadmap

## Ближайшие задачи

- Постоянная статистика: график последних упражнений, где скорость растёт вверх, а ошибки уходят вниз. Там же показывать прогресс относительно предыдущих завершённых упражнений.
- Разобраться с редким ранним рестартом или переключением упражнения после запуска приложения.
- Гибкий ввод табуляции: если в сниппете ожидается `Tab`, принимать либо реальную табуляцию, либо ровно настроенное количество пробелов. В подсказках попеременно мигать Tab и Space.
- Тематические пулы упражнений: Go channels, goroutines, maps, slices, syntax drills и другие сфокусированные наборы.
- Модель typed buffer: если вместо Enter в конце строки нажали неправильный символ, он должен появиться на текущей строке и не должен перебрасывать пользователя на следующую строку до реального Enter.
- Кастомные звуки: выбор своего файла для звука ошибки, при этом оставить текущий сгенерированный fallback.
- Пресеты тем: сохранять и переключать полноценные цветовые пресеты, включая непрозрачные темы приложения без blur/transparency.
- Ресёрч и переключатель подсветки синтаксиса: изучить готовые веб-библиотеки вроде Shiki, Prism, Highlight.js или CodeMirror, затем добавить режим блокнота без подсветки и IDE-режим с подсветкой.
- Полировка выделения текста: выделяемым должен быть только код; UI и номера строк должны оставаться невыделяемыми.
- Продолжить декомпозицию фронтенда: вынести оставшиеся зоны ответственности `main.js` в модуль completion flow.
